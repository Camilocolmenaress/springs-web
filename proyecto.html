01
Instalar VS Code
Es el editor de código que vas a usar. Gratis, el más popular del mundo.
Busca "VS Code" en Google → Descargar → Instalar
💡 Es como Word pero para código. Abre archivos .html, .tsx, .css y los muestra con colores.

Instalar Node.js
Es el motor que hace correr el proyecto de Next.js en tu computadora.
Busca "Node.js download" → versión LTS → Instalar
03
Verificar que funcionó
Abre la Terminal (Mac: Cmd+Espacio → escribe "Terminal").
node --version
Si ves algo como v20.x.x — listo. Si ves un error, reinstala Node.js.

Crear tabla products
id uuid PRIMARY KEY DEFAULT gen_random_uuid() nombre text NOT NULL descripcion text precio integer NOT NULL categoria text CHECK (categoria IN ('jacket','loaded','extra','bebida','combo')) disponible boolean DEFAULT true imagen_url text orden integer DEFAULT 0
