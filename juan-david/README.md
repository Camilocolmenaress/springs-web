## Qué va aquí

### Marca y activos visuales
- Logos (wordmark "SPRINGS", logomark "S gestual") — archivos fuente y exportados
- Paleta cromática de referencia con ejemplos de uso correcto
- Guías de tipografía (Anton, Inter, JetBrains Mono)
- Moodboards de referencia estética

### Copy e interfaz
- Textos definitivos para cada sección del sitio
- Nombres de productos, descripciones, CTAs
- Reglas de tono de voz para la interfaz
- Lista de palabras prohibidas y permitidas

### Campañas
- Briefings de campañas (RÓBALA, Miércoles de Dados, Springs Drop)
- Ideas nuevas antes de ejecutarlas
- Resultados y aprendizajes de cada campaña

### Contenido de redes
- Calendario de contenido (Instagram, TikTok)
- Guiones de videos
- Captions y copies para posts
- Estrategia de embajadoras BGA

### Decisiones de negocio
- Pricing y cambios de carta
- Estrategia de lanzamiento Bucaramanga
- Notas de reuniones con socios

## Lo que NO va aquí
- Código fuente del sitio — eso es de Camilo (`/camilo`)
- Configuraciones técnicas (Supabase, Vercel, Wompi)
- Archivos de deployment o infraestructura

---

## Cómo trabajar
1. Si tienes una idea de contenido o copy → escríbela aquí primero
2. Si necesitas un cambio visual en el sitio → documéntalo aquí, luego se lo pasas a Camilo como brief
3. Si apruebas un texto definitivo para el sitio → márcalo como `[APROBADO]` para que Camilo lo implemente
